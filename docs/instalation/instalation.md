# Загрузка

В настоящее время загрузкаприложения невозможна как для Android так и для IOS, но сами тербования уже спрогноизированны.

## Системные требования

| Параметр            | Требования     |
| ------------------- | -------------- |
| Android версия      | 10+            |
| Свободная память    | 30 мб          |
