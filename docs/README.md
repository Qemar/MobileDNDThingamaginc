# D&DGen - помощник создания персонажа ДнД 5е <!-- {docsify-ignore} -->

**D&DGen** - это приложение помощник для начала игры в самую популярную настольную ролевую игру - D&D 5e.
Оно помогает всего за несколько минут создать своего первого персонажа без необзодимости ручного заполнения и сверки с книгами правил.

Главной особенностью является наличие только самого нужного функционала, без наличия невообразимого количества различного функционала не связанного с главной задачей - механическое создание персонажа.
>Паралич выбора (аналитический паралич) — это психологическое состояние, при котором избыток вариантов или информации приводит к невозможности принять решение.
