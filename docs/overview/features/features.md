# Функции приложения D&DGen

Приложение предоставляет пользователям самый необходимый функционал:

- **Управление персонажами игрока:** создание, редактирование и удаление персонажей.
- **Off-line функционал:** для основного функционала работы приложения не нужно интернет подключение.
- **Перенос персонажей:** возможность эскпорта и импорта файлов созданных персонажей.

Если вы хотите узнать, для кого разработано приложение, ознакомьтесь с разделом [Целевая аудитория](../audience/audience.md).

Более общий обзор возможностей доступен в разделе [Обзор](../overview.md).
