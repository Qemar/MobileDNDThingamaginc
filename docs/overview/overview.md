# Обзор

Приложение-помощник помогает быстро и безошибочно создать персонажа для вашей первой игры в ДнД.

## Основные возможности

- Создание персонажей.
- Эспорт и Импорт файлов.
- Работа без интернет подключения.

Подробнее о функциях читайте [здесь](features/features.md).

## Основная аудитория

Приложение-помощник будет полезно как и новичкам игры так и ветеранам что желают быстро создать персонажей.

Подробнее об адитории читайте [здесь](audience/audience.md).
